Avantages

Un coffre sous contrôle. Zero-knowledge.

Chiffrement local, sync discrète, mêmes secrets sur le web et le desktop. Clefkey est pensé pour que vos clés restent les vôtres.

  • Zero-knowledge Vos mots de passe sont chiffrés sur votre machine. Le serveur ne voit jamais le contenu du coffre en clair.
  • Passphrase + maître Soft-lock rapide avec la passphrase, déverrouillage complet avec le mot de passe maître (8 caractères min.).
  • Web et desktop Un seul compte pour le navigateur et l’app native. Même coffre, mêmes clés, sans ressaisie.
  • Récupération Clés de récupération générées à l’inscription pour retrouver l’accès si le mot de passe maître est perdu.
  • Partage sécurisé Partagez une entrée avec un autre compte Clefkey sans exposer le contenu hors du chiffrement de bout en bout.
  • Open source Code auditable sur GitHub. Builds Windows et macOS publiés via les releases officielles.
